# 状态转换与动效决策（state-transitions）

> 界面状态变化的**反馈决策篇**：一个变化发生时，要不要给动效、给什么反馈、
> 打断后回退到哪——按「触发 → 当下反馈 → 最终状态 → 中断/回退」四格判定，
> 不按「能做什么动画」判定。本篇不是第二套截图协议（截图证据归
> [visual-review](visual-review.md)，条件加载），也不是第二套时长/曲线
> token（数值真源归 [design-tokens](design-tokens.md#动效与交互状态)）。

## 用途与触发场景

任务触及下列信号类之一时读本篇；纯静态呈现、纯数据/文案任务不读：

- **显隐**：弹层 / 抽屉 / 提示 / 骨架 → 内容的出现与消失。
- **移动与缩放**：元素位置、大小的变化（含拖拽、调整大小的跟手判定）。
- **内容 / 图标 / 数值替换**：同一占位里内容换值（加载 → 数据、旧值 → 新值、
  图标切换）。
- **按压 / 悬停**：hover、active、focus-visible、disabled 的过渡。
- **加载 / 完成 / 出错**：异步状态转换的当下反馈与终止态。

## 状态转换判定程序

对每个命中的变化，按四格记录一次（写入设计产物或交付说明，一处一行）：

```text
触发：<谁引起这次变化——用户操作 / 异步响应 / 系统事件>
当下反馈：<变化开始瞬间用户看到什么——无反馈即漏反馈>
最终状态：<收敛后的稳定态；可观察的最终页面状态>
中断/回退：<动画或请求进行中被打断时从哪里继续；合法答案含「原地不动」>
```

判定规则（每条可执行、可观察）：

- **有变化先判要不要反馈**：用户不可见的状态差异不补动效；可见状态差异
  必须有一格反馈（动效、即时替换、骨架或文案占位其一），「静默替换」是
  缺陷不是风格。
- **「不动」是合法决定**：变化位置已定、内容量级小、频率高时，即时替换
  优于动效；记录「不动」及其理由即完成判定，不为了显得有设计而加动画。
- **高频更快**：高频动作（列表行操作、悬停、按压）反馈时长取短档；
  低频登场（抽屉、完成态）取中档。数值跟真源，不在页面散落时长字面量
  （真源与取值纪律见 [design-tokens](design-tokens.md#动效与交互状态)）。
- **中断从当前态续演**：动画或请求途中反向（打开中关闭、切换记录、
  主题切换）不得从头重播或跳变到初始态；拖动与调整大小直接跟手，
  不经动效队列（模板没有这类操作就不造，见 SKILL.md Boundaries）。
- **减动效首帧即生效**：`prefers-reduced-motion` 在首次渲染前生效，
  运行中切换即时跟随，不另加开关；降级方案是移除位移/缩放、保留透明度
  变化或即时替换（与 design-tokens 同口径）。
- **不打断用户控制**：状态变化不得吞掉输入、焦点与选中——慢保存期间
  原输入保留在屏幕上、连续操作不丢焦点、切换记录不串值；这些归
  [general-pages](general-pages.md#操作反馈与用户控制) 的用户控制规则，
  本篇只判反馈形态。
- **保留输入 ≠ 可编辑 ≠ 可取消**：在途写入（提交、删除）表单/控件
  disabled——已输入的文字留在原地但不可再改，防「改了没保存还以为
  保存了」；可安全取消的是未发出的操作，已发出的请求不回滚。删除确认
  同理：初始焦点给安全动作；请求发出后不再提供假撤销。如果允许关闭，
  应说明动作仍在后台进行；否则保留进行态，防止重复提交。

## 五类信号判定表

| 信号类 | 触发例 | 当下反馈 | 最终状态 | 中断/回退 |
| --- | --- | --- | --- | --- |
| 显隐 | 打开弹层 / 关闭抽屉 | 出现即见骨架或内容；消失即释放焦点回触发处 | 弹层开 / 关且焦点归位 | 打开中点关闭：从当前进度关，不播完再关 |
| 移动缩放 | 展开侧栏 / 调整面板宽 | 跟手或短档过渡 | 到达声明尺寸 | 拖到中停即停；不写自动续播 |
| 内容替换 | 骨架→数据、切记录、数值刷新 | 占位先给（骨架/旧值灰显），不空窗 | 新值就位，旧值不串入 | 切 A→B 中再切 C：直接渲染 C，A 不落地 |
| 按压悬停 | hover / active / focus-visible | 组件 token 承载的状态变化 | 指针离开即还原 | 按中移出：回到 hover 或基态，不卡 active |
| 加载完成出错 | 请求发出 / 返回成功 / 返回失败 | 提交态（confirmLoading 或等价）；出错就地提示 | 成功态更新数据；失败态保留原上下文 | 途中新请求：旧响应不得关闭新弹层（请求归属） |

## 动效纪律

- 只动画 `transform` / `opacity`；布局数值变化走 token 真源与布局契约，
  不为动效另开数值体系。
- 防止闪烁与意外布局偏移：内容替换前后占位与实位同尺寸预算；不为动效
  溢出容器、不推挤相邻区域。
- 减动效尊重系统偏好（见上「减动效首帧即生效」）；公开页揭示一次不回放
  的细则在 [public-pages](public-pages.md#交互态与动效)（条件加载）。
- 流畅度声称必须实测：帧率、掉帧、长任务以真浏览器为准——冻结动画的
  截图与 rAF 估算不能作证据；视觉证据协议归
  [visual-review](visual-review.md)（条件加载），本篇不复制。
