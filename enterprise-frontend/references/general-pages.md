# 通用页面规范（general-pages）

> 非地图通用中后台页面规范：布局骨架、CRUD 模式、四态承载、路由弹层终层规则、
> 菜单与路由接线。SKILL.md 路由表「任何页面 / 组件 / 布局工作」默认首读本篇。

## 用途与触发场景

新建页面、扩展既有页面、存量页面修改、页面级一致性审查——进入任何页面/组件/布局
工作前先读本篇，写任何标语、说明文字、标签前先过 [界面删减](#界面删减)；请求与数据面读
[data-layer](data-layer.md)，样式 token 读 [design-tokens](design-tokens.md)，
质量门、接线质量钩子与每次改动的三方体验账读 [engineering](engineering.md)，
地图场景另读地图章节。

## 布局骨架

- **页头槽位废黜**：页面容器 ghost 模式 + `pageHeaderRender={false}` 常开；页面定位
  由菜单当前项与标签页标题承载，页内不再渲染大标题页头。全站默认，非逐页选择。
- **内容壳锁定视口**：页面级滚动不存在；滚动归属 Card body / 表格体
  （卡内滚 + `scroll={{y}}`）。内容壳占满内容区高度。
- **页滚例外必须显式声明**：确需页面级滚动的页面（长表单 / 内容流 / 调试流）传
  `exception` 类别字符串（如 `'long-form' | 'content-flow' | 'debug-stream'`），
  壳回到文档流；未声明的页滚视为违规，审查时直接判定。
- **高度链**：布局 header 高 56（`heightLayoutHeader: 56`），全屏内容页以
  `calc(100dvh - 56px)` 与之对齐；模块目录卡体等嵌套预算按同类 calc 链下探
  （如 `calc(100dvh - 190px)`）。不手写与高度链无关的零散高度值。
- **剩余高度填充**：内容区剩余高度用 `useFillRemainingHeight` 类钩子填充，不手写
  零散高度 hack。
- **模块页骨架 = 样式契约**：模块页目录/卡片骨架是全局样式的样式类契约
  （`.module-catalog-*` 类），不是组件文件；由「样式契约测试」守卫——测试直接读
  样式源断言 CSS 合同。该模式本身入规范：跨文件样式契约必须有同目录读源测试。
- **配套骨架件**：模块统计行、列表批量操作条为通用骨架件，新模块页复用不重造。

## CRUD 模式

中后台内容用 Card / PageShell / ProTable / Modal+Form / Descriptions / Empty / Alert
组织。三类页面的组件选型惯例（目标仓库已有惯例时以其实际形态为准）：

- **列表页 = ProTable（卡内滚）**：ProTable 承载表格列表，滚动归属表格体。
- **编辑/创建页 = Modal + Form**：表单在路由弹层或页内 Modal 中以 antd Form 承载
  （ProForm 为组件面可用项；选型跟随目标仓库既有惯例，不虚构组件使用）。
- **详情页 = Descriptions（+ Drawer 承载）**：只读详情用 Descriptions 分区呈现，
  抽屉/弹层承载。
- **空态与警示**：列表/详情的空态用 Empty、运营警示用 Alert，不自制空态插画体系。

## 四态一致承载

每个数据驱动区块必须有加载 / 空 / 错误 / 禁用四态的一致承载方案，**禁「只有成功态」**：

- **加载态**：Skeleton 骨架族统一承载，不用自旋图标堆砌。
- **空态**：Empty 承载（见 CRUD 节）。
- **错误态**：ErrorBoundary 兜底 + 请求层统一错误处理（错误提示收敛到请求层统一
  入口，页面不自行 toast 轰炸）；401 收敛规则见 [data-layer](data-layer.md)。
- **禁用态**：控件 disabled 视觉由主题 token 承载（防浮层透底的 token 级案例见
  [design-tokens](design-tokens.md)），不在页面写一次性禁用样式。
- **审查口径**：页面审查时逐数据区块核对四态；缺任一态即规范违反，与禁令同级
  硬执行。

## 界面删减

- **删除对象**：标语和口号式副标题；复述标题、控件或字段名已表达之意的说明文字；
  「欢迎使用」「在此处管理……」类引导句；只为「看起来丰富」的装饰性次要标签
  （不携带状态、数量、分类的 Tag / Badge）。
- **删除试读**：先假设这段文字不存在，只看布局：标题、分组、字段顺序、控件形态、
  空态能否让人读懂。读得懂就删。读不懂则**不补文字，重新设计布局**：调整分组与层级、
  字段顺序、控件形态、默认值，直到无字也读得懂；文字补丁不算修复。
- **作用域**：只作用于本次新增或触碰的界面；存量页面不借机整页清洗，与 SKILL.md
  Decision Rules 的最小完整变更一致。
- **自查钩子**（候选清单，不判违规）：
  `grep -rn -e "<Tag" -e "<Badge" -e "subTitle=" -e "tooltip=" -e "description=" -e 'type="secondary"' <目标>`，
  逐处做一遍删除试读；保留的要说得出落在保留清单哪一条。
- **与设计推理衔接**：新页面在 [design-reasoning](design-reasoning.md) 第 4 步产出
  「删减检验」，实现后对照。

**保留清单**（删减到此为止，越过即退化）：

- 四态文案：空态 Empty 描述、错误提示与重试、加载占位。
- 表单校验信息、必填标记，以及不可逆或高风险操作的确认说明。
- 单位、量纲、时区等限定词。
- 承载状态、数量、权限差异的 Tag / Badge。
- 控件的可访问名称：aria-label、纯图标按钮的名称兜底。被删的是可见赘字，不是名称，
  否则读屏用户与 AI Agent 的 role + name 定位一并失效。
- 其他规范条文已要求的用户可见提示：地图超预算降级提示、图例与告警，路由弹层「已是最终页」提示。
- 目标仓库明文要求的合规声明与业务术语。

## Route modal 终层规则

- **弹层是导航终层**：路由弹层内再导航在弹层内终结（提示已是最终页），不用
  iframe / postMessage 跨层通信，不替换父级 pathname。
- **不静默替换**：`openRouteModal` 对已打开的弹层内容不做静默替换。
- **放行清单与路由真源同步**：路由弹层走放行清单机制（`ALLOWED_ROUTE_PREFIXES` 类），
  清单必须与路由真源保持同步，并有一致性测试守卫；漏配新路由 = 静默失败。
- **实现边界**：弹层内部用 MemoryRouter 渲染是允许的实现模式；页面路由/导航禁用
  第三方路由库的禁令语义见 [engineering](engineering.md) B2（命名导出黑名单）。

## 菜单与路由接线

- **双真源分离**：路由真源维护 path/component/access；导航视图真源只控菜单可见性
  （分组、白名单裁剪）。两处同步修改，不在菜单配置里写路由、不在路由里写菜单态。
- **隐藏菜单 ≠ 删除深链**：菜单裁剪只是可见性控制，深链仍可达，授权在后端——
  前端不以前端裁剪替代后端授权。
- **导航视图按角色白名单裁剪分组**：导航分组按角色白名单裁剪（模式级；具体分组
  与角色清单属各仓库真源，不做通用移植）。
- **权限真源**：页面权限键集中声明于权限真源（如 canAdmin 类能力函数），页面以
  access 钩子消费，不散落硬编码角色判断。
- **新页面四步接线**：建组件 → 路由真源 → 导航真源 → 权限 + 测试；步骤验收物与
  质量钩子见 [engineering](engineering.md) §新页面四步接线流程。

## 验证边界声明

本篇约束以静态约束检查与质量命令为验收面；CRUD 组件选型为模式级惯例，
不代表运行时视觉核验。布局高度链、四态视觉表现、弹层交互的最终效果以目标仓库
运行页面为准；本规范不以文档存在代替视觉证据。
